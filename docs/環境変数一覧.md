# 環境変数一覧

`.env.example` の各変数の詳細説明。

## キャラクターDB（PostgreSQL）

| 変数名             | 説明          | 例             |
| ------------------ | ------------- | -------------- |
| `CHAR_DB_NAME`     | DB 名         | `characters`   |
| `CHAR_DB_USER`     | DB ユーザー名 | `app`          |
| `CHAR_DB_PASSWORD` | DB パスワード | ランダム文字列 |

## ユーザーDB（MySQL）

| 変数名                  | 説明                  | 例             |
| ----------------------- | --------------------- | -------------- |
| `USER_DB_NAME`          | DB 名                 | `userdb`       |
| `USER_DB_USER`          | DB ユーザー名         | `app`          |
| `USER_DB_PASSWORD`      | DB パスワード         | ランダム文字列 |
| `USER_DB_ROOT_PASSWORD` | MySQL root パスワード | ランダム文字列 |

## サービス間認証

| 変数名             | 説明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| `INTERNAL_API_KEY` | api ↔ user-dashboard 間の認証キー。`openssl rand -hex 32` で生成する |

- `character-api` は `INTERNAL_API_KEY` で受信リクエストを検証する
- `user-dashboard` は `CHARACTER_API_KEY` としてこの値を使い、`character-api` へのリクエストヘッダー `X-Internal-API-Key` に付与する

## NextAuth（user-dashboard）

| 変数名               | 説明                                                    |
| -------------------- | ------------------------------------------------------- |
| `AUTH_SECRET`        | セッション暗号化キー。`openssl rand -hex 32` で生成する |
| `AUTH_GOOGLE_ID`     | Google OAuth クライアントID（GCP Console で取得）       |
| `AUTH_GOOGLE_SECRET` | Google OAuth クライアントシークレット                   |
| `NEXTAUTH_URL`       | アプリの公開URL（ローカルは `http://localhost:3000`）   |

## その他

| 変数名      | デフォルト | 説明                                                        |
| ----------- | ---------- | ----------------------------------------------------------- |
| `LOG_LEVEL` | `info`     | character-api のログレベル（`debug`/`info`/`warn`/`error`） |
