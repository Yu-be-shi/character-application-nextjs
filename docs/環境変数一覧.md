# 環境変数一覧

`.env.example` の各変数の詳細説明。

各 compose スタックは**自分のディレクトリの `.env` だけ**を読む。このリポジトリの `.env` が
管理するのはアプリスタック（MySQL + Next.js）の変数のみで、キャラクター DB / API の変数
（`CHAR_DB_*` / `REDIS_ADDR` / `LOG_LEVEL` / `CORS_ORIGINS` 等）は `character-db-infra` /
`apis/character-api-go-infra` の `.env` が管理する。

## ユーザーDB（MySQL）

| 変数名                  | 説明                  | 例             |
| ----------------------- | --------------------- | -------------- |
| `USER_DB_NAME`          | DB 名                 | `userdb`       |
| `USER_DB_USER`          | DB ユーザー名         | `app`          |
| `USER_DB_PASSWORD`      | DB パスワード         | ランダム文字列 |
| `USER_DB_ROOT_PASSWORD` | MySQL root パスワード | ランダム文字列 |

## サービス間認証

| 変数名              | 説明                                                                     |
| ------------------- | ------------------------------------------------------------------------ |
| `INTERNAL_API_KEY`  | api ↔ user-dashboard 間の認証キー。`openssl rand -hex 32` で生成する     |
| `RECONCILE_API_KEY` | `/api/internal/reconcile` 専用キー（任意。未設定なら上にフォールバック） |

- `character-api` は `INTERNAL_API_KEY` で受信リクエストを検証する
- `user-dashboard` は `CHARACTER_API_KEY` としてこの値を使い、`character-api` へのリクエストヘッダー `X-Internal-API-Key` に付与する
- **api-go-infra 側の `.env` の `INTERNAL_API_KEY` と必ず同じ値にする**（不一致だと 401）

## NextAuth（user-dashboard）

| 変数名               | 説明                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| `AUTH_SECRET`        | セッション暗号化キー。`openssl rand -hex 32` で生成する                      |
| `AUTH_GOOGLE_ID`     | Google OAuth クライアントID（GCP Console で取得）                            |
| `AUTH_GOOGLE_SECRET` | Google OAuth クライアントシークレット                                        |
| `NEXTAUTH_URL`       | アプリの公開URL（ローカルは `http://localhost:3000`）                        |
| `AUTH_TRUST_HOST`    | ローカル docker（NODE_ENV=production）で UntrustedHost を回避するため `true` |

## compose を使わない場合のみ（`npm run dev`）

| 変数名              | 説明                                                   |
| ------------------- | ------------------------------------------------------ |
| `DATABASE_URL`      | MySQL DSN（compose 利用時は compose が組み立てて注入） |
| `CHARACTER_API_URL` | character-api の URL（compose 利用時は注入）           |
| `CHARACTER_API_KEY` | `INTERNAL_API_KEY` と同じ値（compose 利用時は注入）    |
